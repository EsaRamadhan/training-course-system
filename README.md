# Training Course System

A web-based application for managing course enrollment, schedules, and payments.

## Features
- User & Admin Login
- Course Enrollment
- Payment System
- Schedule Management

## Tech Stack
- PHP
- MySQL
- Bootstrap

## Setup
1. Import database to phpMyAdmin
2. Configure database in config/db.php
3. Run project in XAMPP (localhost)
